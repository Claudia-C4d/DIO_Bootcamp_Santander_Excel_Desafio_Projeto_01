# DIO_Bootcamp_Santander_Excel_Desafio_Projeto_01
Desafio de Projeto - Bootcamp DIO Santander Excel com IA e Claude
READ.me
Esse projeto foi elaborado como um Desafio de Projeto para o DIO Bootcamp Santander - Excel com IA e Claude para a criação de uma ferramenta para de Controle de Investimentos com Excel. 
*Observação: A logomarca e o nome da ferramenta são meramente ilustrativos, e foram criados para o projeto, como parte do estudo. 
Documentos em anexo:
Dio_Desafio_projeto_01_Controle_Investimentos_excel.xlsx
ShapeFi_investimentos_imobiliários.jpg
1.: Dio_Desafio_projeto_01_Controle_Investimentos_excel.xlsx
A ferramenta consta em uma planilha em Excel para a simulação de Investimentos Imobiliários com os seguintes parâmetros:
Configurações: Com os seguintes campos para preenchimento:
- Salário
- Rendimento de Carteira
Investimento Mensal: Com os seguintes campos para preenchimento:
- Quanto investir por mês?
- Por quantos anos?
- Taxa de Rendimento Mensal?
Cenários: Exibe uma tabela configurada por 05 cenários de tempo de investimento e respectivos dividendos
Perfil do Investidor: Para ser preenchido com a seleção em lista suspensa de três possíveis perfis:
- Conservador
- Moderado
-Agressivo
Tipo de FII: Exibe uma tabela com os tipos de investimentos imobiliários sugeridos para cada perfil, ilustrado com um gráfico.
